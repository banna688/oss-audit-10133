## Project Description
This project is based on the study of open-source software Git and its practical implementation using Linux shell scripting.

It includes five scripts that perform system information, package checking, disk usage analysis, log analysis, and manifesto generation.

---

## Scripts
1. script1.sh - System Info  
2. script2.sh - Package Checker  
3. script3.sh - Disk Auditor  
4. script4.sh - Log Analyzer  
5. script5.sh - Manifest Generator  

---

## Environment Setup

sudo apt update  
sudo apt upgrade -y  
sudo apt install git -y

## How to Run

chmod +x script1.sh  
chmod +x script2.sh  
chmod +x script3.sh  
chmod +x script4.sh  
chmod +x script5.sh  

./script1.sh  
./script2.sh  
./script3.sh  
./script4.sh /var/log/syslog  
./script5.sh
